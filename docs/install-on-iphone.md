# Install Workout on your iPhone

You do not need the App Store or an Apple Developer subscription. You need the website address, an invited Google account, and internet for your first sign-in. Notifications require iOS 16.4 or later.

## Add the app

1. Open the Workout website in **Safari**.
2. Tap **Share** (the square with an upward arrow).
3. Choose **Add to Home Screen**. Scroll down or use **More** if necessary.
4. Keep the name **Workout**, enable **Open as Web App** if shown, and tap **Add**.
5. Open the new Workout icon on your Home Screen.
6. Choose **Continue with Google** and sign in with your invited account. Sign in from the installed app even if you previously signed in through Safari.

## Enable notifications

1. Open **Settings** inside Workout.
2. Find **Notifications** and select **Enable notifications**.
3. Choose **Allow** in the iPhone permission prompt.
4. Choose the alert categories you want, reminder days/time, and quiet hours; select **Save notification preferences**.

The defaults are workout reminders at 6 PM, a Sunday progress nudge at 5 PM, and quiet hours from 9 PM to 8 AM. All times use New York time. Partner check-ins and weekly goal celebrations are included. Reminders skip confirmed workouts or completed weekly goals.

Category settings apply to your account; **Disable on this device** only removes the current phone's subscription. Notification delivery can be affected by Focus, internet access, or server availability.

If permission was denied, open **iPhone Settings → Notifications → Workout** and allow notifications. If Workout is not listed, launch it from the Home Screen icon and try Enable notifications. If the app says notifications are unavailable, its operator needs to configure the server's push keys.

## Work out without internet

After signing in online and loading your screens, you can create workouts and change previously loaded workouts offline. Saved changes appear as **Pending sync**. You can also queue workout deletions. Templates and settings need internet to change.

Reopen Workout when internet returns. It will sync your changes; use **Retry sync** if needed. If your session expired, sign in to the same account first. Offline progress is provisional, and partner alerts wait for server confirmation. A reminder may arrive before an offline check-in has synced.

If another device changed the same workout, the app preserves your changes and shows a comparison. Select **Keep server version**, **Apply my changes**, or **Save as new workout** when the server version was deleted. For invalid data, edit the pending workout in Workouts before applying it again.

## Updates, sign-out, and reinstalling

When **App update available** appears, finish editing and save before selecting **Update app**. Saved pending changes survive normal updates.

Sign-out requires internet. Sync your changes first; signing out with pending changes requires explicitly choosing to discard them.

To remove the app, use the Home Screen icon's removal menu. To reinstall, repeat Add the app above, sign in, and enable notifications again. **Sync every pending workout before removing the app or clearing website data**, because those actions can remove locally stored workouts. Your confirmed server workouts remain available after signing in again.

For server configuration and troubleshooting, see [PWA setup](pwa-setup.md).
